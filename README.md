# Rick and Morty App

Proyecto del curso de Plataformas Móviles.

Este repositorio será utilizado para los laboratorios de la aplicación Rick and Morty desarrollada con Kotlin y Jetpack Compose.

## Estructura de ramas

- `main`: rama principal del proyecto.
- `laboratorio7`: implementación correspondiente al Laboratorio 7.

## Tecnologías

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- Kotlin Serialization
